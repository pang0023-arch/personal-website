# Peisin Ang: Personal Website

My personal website and portfolio, built with [Quarto](https://quarto.org) and hosted on GitHub Pages.

## Featured project

## Built with

- [Quarto](https://quarto.org) for the website
- D3.js, d3-sankey and Scrollama for the interactive story
- R for data cleaning
